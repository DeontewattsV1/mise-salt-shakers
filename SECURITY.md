# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within mise-salt-shakers, please follow our responsible disclosure process:

1. **Do NOT** create a public GitHub issue
2. Send a detailed description to the repository maintainer via GitHub
3. Include the following in your report:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested mitigation (if any)

We aim to respond within 48 hours and will work with you to:

- Confirm the vulnerability
- Determine severity
- Develop and release a fix
- Credit you (if desired) in the release notes

## Security Best Practices

When using this action in your workflows:

- Review the permissions requested
- Use least privilege principles
- Keep action versions pinned
- Monitor workflow runs for unusual activity

## Dependencies

This project depends on external actions. We regularly update dependencies and monitor for known vulnerabilities.
