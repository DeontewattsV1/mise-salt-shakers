# Contributing to mise-salt-shakers

Thank you for your interest in contributing to mise-salt-shakers!

## Development Setup

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/mise-salt-shakers.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`

## Making Changes

1. Make your changes in your feature branch
2. Test locally if applicable
3. Commit your changes with clear, descriptive messages
4. Push to your fork
5. Open a Pull Request against `main`

## Workflow Guidelines

- All workflows should be in `.github/workflows/`
- Workflow filenames should use kebab-case: `workflow-name.yml`
- Avoid spaces in filenames
- Include `permissions:` block for security
- Use `workflow_dispatch` for manual triggers during development

## Code Style

- YAML files should be properly indented (2 spaces)
- Include descriptive comments for complex logic
- Use meaningful job and step names

## Reporting Issues

- Use GitHub Issues for bugs and feature requests
- Include reproduction steps for bugs
- Check existing issues before creating new ones

## Questions?

Feel free to open a Discussion if you have questions about contributing.
